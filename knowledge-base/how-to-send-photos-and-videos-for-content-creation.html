How to send photos and videos for content creation

Deliver media files with enough context for faster production.

Step-by-step instructions

  1. Upload original files to a shared cloud folder.
  2. Create subfolders by date, campaign, or content pillar.
  3. Add notes for message, audience, and preferred usage.
  4. Include brand references and do-not-use restrictions.
  5. Notify PMB-Solutions once all assets are uploaded.

Tips

  • Use horizontal and vertical versions when possible.
  • Avoid compressed files from chat apps if quality matters.
  • Share consent guidance for customer-facing media.
