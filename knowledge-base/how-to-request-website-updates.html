How to request website updates

Submit requests in a way that keeps edits accurate and on schedule.

Step-by-step instructions

  1. List each requested change by page URL and section title.
  2. Provide replacement copy exactly as it should appear.
  3. Attach any new images and note placement instructions.
  4. Flag priority level and desired completion date.
  5. Review staging or live changes and confirm final approval.

Tips

  • Batch related updates to reduce revision cycles.
  • Use screenshots with annotations for layout changes.
  • Avoid mixing urgent fixes with non-urgent edits in one request.
