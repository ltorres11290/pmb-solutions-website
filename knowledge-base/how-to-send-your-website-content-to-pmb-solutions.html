How to send your website content to PMB-Solutions

Organize and deliver copy, media, and references in one clean handoff.

Step-by-step instructions

  1. Create one folder with subfolders for text, images, and documents.
  2. Provide finalized page copy in DOCX, Google Doc, or text files.
  3. Name images clearly by page/section and include source notes.
  4. Share access using Google Drive, OneDrive, or Dropbox.
  5. Confirm any missing content and expected delivery date.

Tips

  • Include a style note if a section should feel formal or casual.
  • Use original image files when possible.
  • Send one update batch instead of multiple small uploads.
