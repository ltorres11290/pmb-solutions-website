How to back up your files properly

Protect critical data with a simple repeatable backup process.

Step-by-step instructions

  1. Identify business-critical files and folders first.
  2. Use both cloud backup and an offline external drive.
  3. Set daily automatic backups for active data.
  4. Enable version history to recover older file versions.
  5. Test a restore every month to verify backups are usable.

Tips

  • Follow the 3-2-1 backup rule.
  • Encrypt backups containing sensitive information.
  • Document where backups are stored and who can access them.
