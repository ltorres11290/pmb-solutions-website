Branding & Graphics

What files you receive with a logo package

Understand the file types and where to use each one.

Step-by-step instructions

  1. Review vector files (AI, EPS, SVG) for print and scaling.
  2. Use PNG files for transparent digital usage.
  3. Use JPG files for quick sharing and previews.
  4. Locate color variations: full color, black, white, and mono.
  5. Store all files in a shared brand folder for your team.

Tips

  • Never recreate the logo manually in new software.
  • Keep the original vector source file backed up.
  • Use brand guide spacing and minimum-size rules.
